# ReviewForge Pro

Advanced Elementor-based review system for any post.

## Installation and use

Place the `reviewforge-pro` directory in `wp-content/plugins/` and activate **ReviewForge Pro** from the WordPress Plugins screen.

Built for Elementor. The review form, list, and summary template files are empty in this development snapshot.
